# 📋 Актуальные задачи агентов

> Этот файл — очередь задач. **main_agent** пишет сюда промпты для под-агентов.
> Агент читает свои задачи, выполняет, затем:
> 1. Стирает тело промпта из этого файла (оставляет только заголовок со статусом ✅).
> 2. Переносит полный текст промпта в свой файл архива: `agent_tasks/old_prompts_<имя>.md`.

---

## Как агенту работать с этим файлом

Когда ты (любой под-агент) открываешь новый чат:
1. Прочитай `MEMORY_BANK.md` — пойми структуру проекта.
2. Прочитай `memory_bank/agent_instructions.md` — правила кода.
3. Прочитай **этот файл** (`agent_tasks/current_tasks.md`) — найди раздел со своим именем.
4. Выполни задачу.
5. После выполнения:
   - Замени тело промпта на `✅ Выполнено — [дата]`.
   - Перенеси **полный оригинальный текст промпта** (дословно, как он был) в `agent_tasks/old_prompts_<твоё_имя>.md`. НЕ пиши краткий пересказ — только оригинал.
