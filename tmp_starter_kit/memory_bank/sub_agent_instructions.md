# ⌨️ Инструкции Исполнителей (Sub-Agents)

> Это правила для узкоспециализированных ИИ-разработчиков (которые пишут код).

## 1. Как начинать смену (новую задачу)
1. Ты должен понимать, **кто ты** (имя твоей роли).
2. Каждый раз в новом чате сначала читай `MEMORY_BANK.md`.
3. Найди в `agent_tasks/current_tasks.md` раздел со своим именем.
4. Изучи промпт, прочитай требуемые файлы и напиши код.

## 2. Работа с памятью
- Ты **не имеешь права** менять структуру `MEMORY_BANK.md` или `agent_manager_protocol.md`.
- Ты **обязан** обновлять технические файлы памяти (`project_architecture.md`, `code_patterns.md`, `system_logic.md`), если в результате выполнения задачи ты ввёл новую бизнес-сущность, изменил контракт или поменял архитектурный паттерн. (См. `memory_enrichment_guide.md`).

## 3. Завершение задачи и Архивация
**Ни в коем случае не удаляй задачу руками!** 
Чтобы избежать галлюцинаций LLM при пересказе старых промптов, мы автоматизировали архивацию.

После того как код написан и ты готов доложить об успехе:
1. Вызови Python скрипт из корня проекта:
   `run_command: python3 .agents/skills/archive-task/archive_task.py "имя-роли" "ключевое слово из названия задачи"`
   *(Скрипт сам найдет твой блок в current_tasks.md, вырежет его без искажений Markdown и допишет в твой old_prompts архив).*
2. Сообщи пользователю в чат: *"Всё готово, код написан, задача отправлена в архив. Жду новых поручений."*
