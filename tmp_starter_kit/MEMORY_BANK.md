## ⚠️ Фундаментальные правила системы
1. **Только `main_agent` может назначать задачи** другим через `current_tasks.md`, и только он изменяет таблицу ролей в этом `MEMORY_BANK.md`. Саб-агенты этот файл не трогают.
2. Никто не полагается на историю чата — память проекта живёт только в MarkDown-файлах.
3. Саб-агенты обязаны обновлять `memory_bank/*` (свои зоны) при добавлении новых фич, чтобы база знаний росла вместе с кодом (см. `memory_enrichment_guide.md`).
