# Система Дизайна (Design System)

## Цветовая палитра
Вся игра использует централизованную систему цветов, построенную вокруг двух главных оттенков (определены в `AppStyles`):

1. **primaryBg (Основа): `#2C3E50`**
   - Глубокий, тёмно-синий кэжуал цвет.
   - Используется как основной фон приложения.
   - Заменяет старый светлый фон и любые явные указания черного/белого.

2. **primaryAccent (Акцент): `#EBC462`**
   - Теплый золотисто-бежевый оттенок.
   - Используется для основного текста, заголовков и акцентных элементов управления (кнопок).

## Зависимые цвета
Для элементов, требующих выделения (карточки, тени, второстепенный текст), используются зависимые оттенки, рассчитанные от основных:
- `cardBg`: `#34495E` (Слегка осветленный `primaryBg`) — фон для карточек.
- `darkAccent`: `#1A252F` (Затемненный `primaryBg`) — тени, обводки, акценты в глубине.
- `textSecondary`: `#95A5A6` или `0x99EBC462` — приглушенный или полупрозрачный текст для второстепенной информации.

## Фон-паттерн
Класс `AnimatedPatternBackground` был переработан. Отключены анимация горизонтальных "crt" сканирующих полос для обеспечения чистоты интерфейса. Виджет теперь работает как простой контейнер с заливкой `primaryBg` по умолчанию.

## Правила кодинга
- **ЗАПРЕЩЕНО** использовать сырые цвета напрямую: `Colors.white`, `Colors.black`, `Colors.grey`.
- **ЗАПРЕЩЕНО** использовать хардкод HEX-кодов `Color(0xFF...)` вне классa `AppStyles`.
- Все семантические цвета (успех `Colors.green`, ошибка `Colors.red`) остаются в `AppStyles` как `success`, `danger` и `warning`.
