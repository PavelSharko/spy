# 📱 Макро-план адаптации UI (Spy Game)

## Вводные правила
1. **Цвета не трогаем.**
2. **Только динамические размеры:** отказ от жесткой ширины (`width: 300`) и высоты в пользу `Flexible`, `Expanded`, `MediaQuery.sizeOf(context)` и `LayoutBuilder`.
3. **Безопасные зоны:** обязательное использование `SafeArea` для предотвращения налезания элементов на челки и скругленные углы экранов.
4. **Адаптивные отступы:** вместо `SizedBox(height: 20)` используем пропорции по высоте экрана.
5. **Безопасность текста:** текст должен переноситься или скейлиться (`FittedBox`, `AutoSizeText` (если есть), либо `overflow: TextOverflow.visible/ellipsis`), если не влезает.
6. **Высочайшее качество:** пишем код как бест-практис, с заделом на будущее.

## Размеры эталонов (Safe Areas & Ratios)
- **iOS (iPhone 15/16):** 393 x 852 pt (19.5:9)
- **Android:** 360 x 800 dp (20:9)
- **Универсальная цель:** дизайн должен мягко "дышать" в диапазоне ширин 320px - 450px и высот 650px - 950px.

### 2. GameRoundScreen (Игровой раунд)
*Текущий статус:* ✅ ВЫПОЛНЕНО.
*Что сделано (uix-agent):*
1. **Главный таймер сверху:** Жесткий отступ `horizontal: 80` заменен на `horizontal: context.screenWidth * 0.15`.
2. **Имена игроков:** Обернуты в `FittedBox()`, больше не ломают желтую полоску даже с самыми длинными никами.
3. **Круглый таймер вопроса:** Теперь его ширина и высота высчитываются динамически: `context.screenWidth * 0.35` (с жесткими границами 100-180 px), а текст внутри него обернут в `FittedBox`.
4. **Проблема с Подсказками:** Полностью переработана архитектура экрана. Теперь кнопки "ДАЛЬШЕ!" и "Завершить раунд", а также баннер — **навсегда прибиты к нижнему краю экрана**. Вся центральная часть (игроки, подсказки, круглый таймер) обернута в `Expanded` + `SingleChildScrollView`. Если подсказок много, скроллится только центр, а главные кнопки действий всегда под рукой!
5. **Наслоения нотификаций:** Текст "Последний вопрос" убран из кривого `Positioned(top: -120)`. Теперь он находится в потоке виджетов (над кнопками действий) и появляется плавно через `AnimatedOpacity`, не ломая верстку и не загораживая кнопки.


### 5. GameSettingsScreen (Настройки раунда)
*Текущий статус:* ✅ ВЫПОЛНЕНО.
*Что сделано (uix-agent):*

- Жесткая высота `80` в `SettingsButton` убрана, виджет теперь принимает параметр `height` и использует `FittedBox` для обрезки текста.

## 🌟 Общие правила для всех экранов (Новые Требования):
1. **Оптимальный отступ сверху:** использовать единую логику для SafeArea на всех экранах (например, `SizedBox(height: screenHeight * 0.03)`).
2. **Симметричное центрирование:** все элементы должны оставаться симметрично по центру (если не было задумано иное).
3. **Адаптивное растягивание на планшетах (Max Width):** использовать `Center` + `ConstrainedBox(maxWidth: 600)` или подобный паттерн, чтобы UI смотрелся аккуратно и не размазывался по краям огромного iPad.
4. **Рекламный баннер:** В `game_round_screen.dart` добавлено место для нижнего рекламного баннера стандартного размера под условием `subscribe_payed == false`. В будущем нужно продумать это для всех нужных экранов.
