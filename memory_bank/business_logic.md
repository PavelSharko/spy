## 1. Игровой цикл (Game Flow)

```
MainMenuScreen
    │
    ▼
GameSettingsScreen           ← Выбор: игроки (3–6), время, раунды (1–5), локация, стиль карт
    │
    ▼
LocationSelectionScreen      ← Выбор группы локаций или случайный подбор
    │
    ▼
PreGameFlowScreen            ← Для каждого игрока: выбор имени → [Фото мордахи] → flip-карточка (роль/локация)
    │
    ▼
GameRoundScreen              ← Таймер (20 сек/ход + 3 сек бонус), подсказки, переход ходов
    │                          ↑ (Генерация карточек запускается в фоне через 6/12сек)
    │
    ├─ Стоп-раунд (кнопка) ──────►  Опции: "Шпион угадал" / "Провал шпиона" / "Продолжить"
    │
    ▼
VotingScreen                 ← Каждый игрок голосует за подозреваемого
    │
    ▼
VotingResultScreen           ← Шпион найден / не найден
    │
    ├─ Шпион найден ──►  SpyLastWordScreen (угадай локацию)
    │                         │
    │                         ▼
    │                    RoleGuessScreen (мини-игра "Угадай роль")
    │
    ├─ Шпион не найден ──► RoundScoreScreen (шпион получает 2 очка)
    │
    ▼
RoundScoreScreen             ← Таблица очков раунда
    │
    ├─ Есть ещё раунды → PreGameFlowScreen (следующий раунд)
    └─ Последний раунд → Финальный рейтинг → MainMenuScreen
```

## 2. Локации

### Группы (10 групп × 10 локаций = 100 локаций)

| # | Группа |
|---|---|
| 1 | Городская повседневность |
| 2 | Работа и бизнес |
| 3 | Путешествия и транспорт |
| 4 | Развлечения и встречи |
| 5 | Образование и культура |
| 6 | Опасные и экстремальные |
| 7 | Фэнтези миры |
| 8 | Космос и sci-fi |
| 9 | Киновселенные |
| 10 | Исторические эпохи |

### Выбор локации

- **Фиксированная группа:** Для каждого раунда из выбранной группы выбирается `N` разных локаций (N = кол-во раундов)
- **Случайный выбор:** Из ВСЕХ групп по алгоритму `pickSmartLocations` из `StorageService`
- `secretLocationsQueue` — предвычисленная очередь секретных локаций на все раунды

### Роли

- У каждой локации — пул из 10 ролей (`LocationsData.roles`)
- Роли назначаются через `GameSession.assignRoles()` — случайное перемешивание
- Если игроков больше чем ролей — роли повторяются (`roleIndex % pool.length`)
- **Шпион** всегда получает `role = null`

## 3. Система очков (Scoring)

Все константы в `GameRules` (`lib/utils/game_rules.dart`):

| Событие | Очки | Константа |
|---|---|---|
| Шпион угадал локацию (mid-game) | +4.0 шпиону | `spyWinsGuessCorrect` |
| Шпион НЕ найден голосованием | +2.0 шпиону | `spyNotFound` |
| Шпион найден, но угадал локацию | +1.0 шпиону | `spyGuessedAfterFound` |
| Мирные нашли шпиона | +1.0 каждому мирному | `civiliansWinsVote` |
| Угадал роль (мини-игра) | +1.0 угадавшему | `roleGuessCorrectGuesser` |
| Чью роль угадали | +1.0 владельцу роли | `roleGuessCorrectGuessed` |
| Не ответил вовремя | −0.1 (штраф) | `penaltyOvertime` |

## 4. Таймер

### Основной таймер хода
- **20 секунд** на ход (`GameRules.questionTimerSeconds`)
- После окончания — **3 секунды** бонусного времени (`GameRules.overtimeSeconds`)
- Бонусное время отображается пульсирующим таймером на кнопке
- Если не нажал «Дальше» за 3 секунды — штраф −0.1

### Общий таймер раунда
- Устанавливается в настройках (зависит от кол-ва игроков)
- `minGameTime = playerCount`, `maxGameTime = ceil(playerCount * 1.5)`
- По истечении — раунд завершается

---

## 5. Голосование

- Каждый игрок по очереди выбирает, кого считает шпионом
- Подсчёт голосов → игрок с max голосами объявляется подозреваемым
- **Ничья** → шпион НЕ найден (проигрывается звук "pig")
- Если подозреваемый = шпион → «Шпион найден!»
- Если подозреваемый ≠ шпион → «Шпион не найден!»

## 6. Подсказки (Hints)

### Приватные подсказки
- Привязаны к конкретной локации.
- Хранятся в `locations_stats.json` → `hints_private[]`.
- Каждая подсказка помечается `hint_choosed_times` (0 = не использована).
- Сбрасываются в конце раунда (`resetPrivateHints`).

### Система перемешивания пулов подсказок (Shuffling Pool System)
Для обеспечения баланса и реиграбельности в игре реализована система перемешивания приватных подсказок, разделенная на две независимые половины:
- **Пул A:** Группы 1–5 (индексы групп 0–4 в `locations_data.dart`).
- **Пул B:** Группы 5–10 (индексы групп 4–9 в `locations_data.dart`).

**Правила перемешивания (Shuffling Rules):**
1. **Блокировка подсказок #1 и #2 (Locking Rule):** Первые две подсказки в каждой локации жестко зафиксированы и не перемешиваются. Это гарантирует, что у игрока всегда останутся качественные, уникальные атмосферные вопросы для данной локации.
2. **Перемешивание подсказок #3, #4 и #5 (Shuffling & Bluffs):** Подсказки с индексами 2, 3 и 4 изо всех локаций внутри пула собираются в общий массив, тщательно перемешиваются и случайным образом распределяются обратно в локации на позиции 3–5. 
   - Это создает эффект *абстрактного блефа*: шпион не может вычислить локацию по третьему, четвертому или пятому вопросу, так как они прилетают из абсолютно других мест, а мирные игроки могут использовать их для запутывания шпиона.

### Правила составления подсказок (Abstract Hint Guidelines)
Для сохранения высокой интриги все подсказки составляются по правилам глубокой абстракции:
- **Отказ от прямых деталей (No Lore-Specific Clues):** Никаких спойлеров и очевидных вещей (например, вместо "магия" для Хогвартса пишется "странные обитатели" или "необычные законы").
- **Развлекательный абсурдизм (Playful Absurdism & Bluffs):** Использование ложных вопросов-блефов (например, "Тут владеют кунг-фу?" для Мордора или "Тут есть вредные бабки?" для Матрицы). Это путает шпиона и создает комедийный эффект.
- **Живой разговорный тон (Colloquial Tone):** Подсказки звучат естественно и с юмором (например, "как тут поатить?", "бабайки?").

### Универсальные подсказки
- Общие для всех локаций
- Хранятся в `universal_hints.json`
- Выбираются по принципу round-robin (наименее использованная)
- Когда все использованы одинаково — счётчики сбрасываются

## 7. Имена игроков

- Генерируются через `NamesData.generateRandomName()`
- Формат: «Качество + Существительное» (например, «Сонный кальмар»)
- Первая буква — заглавная
- Игрок может перегенерировать имя на этапе `PreGameFlowScreen`

---

## 8. Мини-игра «Угадай роль» (RoleGuessScreen)

- Запускается **только** если шпион найден голосованием
- Каждый мирный игрок по очереди угадывает роль другого мирного
- Правильный ответ: +1 угадавшему + 1 чью роль угадали
- Неправильный ответ: 0 очков обоим
- Шпион в мини-игре не участвует

## 9. Настройки приложения (AppSettings)

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `soundEnabled` | bool | `true` | Вкл/выкл звуковые эффекты |
| `developerFeaturesEnabled` | bool | `false` | Скрытые функции (skip timer и др.) |
| `uniqueCardsEnabled` | bool | `true` | Вкл/выкл AI-генерацию финальных карточек |
| `playerFacesEnabled` | bool | `true` | Вкл/выкл этап фото игрока перед раундом |
| `cardStyle` | string | `не выбрано` | Стиль генерации (напр., "киберпанк"). Fallback: "реальное фото" |

> Настройки хранятся в **SharedPreferences** — сохраняются между сессиями на всех устройствах (Android/iOS/Web).

## 10. Уникальные карточки (Unique Cards System)

### Архитектура генерации
1. **Захват фото**: На этапе `PreGameFlowScreen` игроки делают фото мордахи (если `playerFacesEnabled`). Фото хранится как `Uint8List` в объекте `Player`.
2. **Триггер**: В начале раунда (`GameRoundScreen`) через 6 и 12 секунд (`AiGenerationService`) асинхронно отправляет данные раунда и фото всех игроков на webhook (n8n).
3. **Webhook Transfer**: Используется `multipart/form-data` с ручной сборкой body (для обхода ограничений Dart по кодировке полей). Текстовые поля (локация, роли, стиль) приходят в `body`, фото — в `binary`. Роли передаются через bracket-нотацию (`roles[0]`, `roles[1]`).
4. **Кэш**: Полученные `Uint8List` сохраняются в `session.roundFinalCards[round]`.
5. **Отображение**: На экране `RoundScoreScreen` в конце раунда выводится карточка, соответствующая исходу игры.

### Аватарки (CircleAvatar)
Если фото захвачено, оно отображается в `VotingScreen` и `RoundScoreScreen` рядом с именем игрока для облегчения идентификации.
