# 📁 Каталог Ассетов (Assets Catalog) — Spy Game

Этот файл содержит полный список всех звуковых эффектов и графических ассетов, используемых в игре, а также перспективные ассеты, которые планируется внедрить для максимального погружения.

---

## 🎵 1. ЗВУКОВЫЕ ЭФФЕКТЫ (AUDIO)

Рекомендуемый формат для коротких эффектов (клики, шорохи): **`.wav`** (быстрый отклик без задержек).  
Рекомендуемый формат для длинных звуков и эмбиента: **`.mp3`** (компактный размер).

Все файлы должны быть размещены в директории: `assets/audio/` и зарегистрированы в `lib/utils/game_sounds.dart`.

### Текущие (уже используются в коде):
| Название переменной | Имя файла | Формат | Описание | Когда воспроизводится |
| :--- | :--- | :--- | :--- | :--- |
| `buttonClick` | `pulk.wav` | `.wav` | Легкий технологичный клик | При нажатии на любую интерактивную кнопку во всем приложении |
| `cardFlip` | `whoosh.wav` | `.wav` | Шпионский взмах/шелест карточки | При тапе по игровой карте для просмотра роли/локации |
| `overtimeSiren` | `siren_short.wav` | `.wav` | Краткий тревожный сигнал сирены | Воспроизводится каждую секунду во время 3-секундного овертайма |
| `tiePig` | `pig.wav` | `.wav` | Забавный визг свиньи | При ничьей во время голосования игроков |

### Перспективные (рекомендуется сгенерировать и подложить):
| Имя файла | Формат | Описание / Идея звука | Когда воспроизводится |
| :--- | :--- | :--- | :--- |
| `game_start.wav` | `.wav` | Звук затвора пистолета или сканера сетчатки глаза | При нажатии «Начать раунд» в меню подготовки |
| `camera_shutter.wav` | `.wav` | Классический механический щелчок объектива камеры | При успешном фотографировании игрока на аватар |
| `vote_confirm.wav` | `.wav` | Глухой электронный пик или удар по металлу | При нажатии на игрока во время фазы голосования |
| `timer_tick.wav` | `.wav` | Напряженное тиканье механических часов | В последние 5 секунд основного таймера раунда |
| `spy_win.wav` | `.wav` / `.mp3` | Саспенс, злодейский кибер-смех или хакерский взлом | На экране результатов, если победил шпион |
| `locals_win.wav` | `.wav` / `.mp3` | Героические фанфары или сирены спецслужб | На экране результатов, если шпион проиграл |
| `ambient_music.mp3` | `.mp3` | Легкий, циклический шпионский неоновый эмбиент (саундтрек) | На протяжении всей игры (в меню и настройках) в фоновом режиме |

## 🖼️ 2. ГРАФИЧЕСКИЕ АССЕТЫ (IMAGES)

Рекомендуемый формат для иконок и интерфейса с прозрачностью: **`.png`**.  
Рекомендуемый формат для карточек, локаций и плотных фонов: **`.jpeg`** / **`.jpg`** (сжатие для уменьшения веса приложения).

Все файлы должны быть размещены в директории: `assets/images/` и зарегистрированы в `lib/utils/app_images.dart`.

### Текущие (уже используются в коде):
| Название переменной | Путь к файлу | Формат | Рекомендуемое разрешение | Описание |
| :--- | :--- | :--- | :--- | :--- |
| `appIcon` | `assets/images/app_icon.png` | `.png` | `512x512` | Логотип игры в главном меню (шпионская иконка) |
| `bgCardBack` | `assets/images/bg_card_back.jpeg` | `.jpeg` | `600x900` | Рубашка игровой карточки (когда она лежит закрытой) |
| `revealBgSpy` | `assets/images/card_reveal_bg_spy.jpeg` | `.jpeg` | `600x900` | Дефолтная карточка шпиона (красно-черный силуэт/паттерн) |
| `revealBgNotSpy` | `assets/images/card_reveal_bg_not_spy.jpeg` | `.jpeg` | `600x900` | Дефолтная карточка мирного (Fallback-карточка локации для неподписчиков) |
| - | `assets/images/card_after_round_defolt_spy_win.jpeg` | `.jpeg` | `600x900` | Финальная карточка «Шпион выиграл» (если уникальные карты отключены) |
| - | `assets/images/card_after_round_defolt_spy_lose.jpeg` | `.jpeg` | `600x900` | Финальная карточка «Шпион проиграл» (если уникальные карты отключены) |

### Локации по умолчанию (Defaults):
Картинки по умолчанию для каждой из 100 локаций (10 групп по 10 локаций в каждой).
- **Путь:** `assets/images/defaults/group_X/X-Y.jpeg` (где `X` — группа 1..10, `Y` — локация 1..10).
- **Формат:** `.jpeg` / `.jpg`.
- **Рекомендуемое разрешение:** `600x900` (вертикальный формат карты).
